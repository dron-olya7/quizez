Quizez — это современное одностраничное (SPA) веб-приложение для создания и прохождения теста (квиза), построенное на чистом JavaScript с использованием классов, модулей и сборщика Webpack.

*Проект был разработан в качестве практического задания для глубокого погружения в основы фронтенд-разработки, включая работу с API, управление состоянием и организацию кода.*

## Возможности

- **Прохождение тестов**: Пользователь может выбрать тест, ответить на вопросы в интуитивно понятном интерфейсе и отправить результаты.

- **Просмотр результатов**: После завершения теста отображается детальный результат с набранными баллами.

- **Анализ ответов**: На отдельной странице можно посмотреть все вопросы теста, свои ответы и сравнить их с правильными вариантами (верные ответы подсвечиваются зеленым, неверные — красным).

- **Авторизация**: Реализована система аутентификации для разграничения функционала.

- **Чистая архитектура**: Проект построен по принципам SPA, используется модульная структура и классы для лучшей поддерживаемости кода.

## Технологии

**Frontend**: JavaScript (ES6+), HTML5, CSS3, Webpack

**Backend**: Node.js

**Архитектура**: SPA, модульная система, классы

## Быстрый старт

Для работы приложения необходимо запустить как фронтенд, так и бэкенд части в разных терминалах.

Предварительные требования

Убедитесь, что на вашем компьютере установлен Node.js (версия 14 или выше).

### Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/dron-olya7/quizez.git
```

***Запуск бэкенда***

```
cd backend
npm install
npm run start
```

***Запуск фронтенда***

```bash
cd frontend  
npm install
npm run dev
```

## История разработки

Этот проект был создан в рамках серии практических уроков, где поэтапно разбирались ключевые аспекты фронтенд-разработки.

Реализация базового функционала на JavaScript: Добавление логики прохождения теста, обработки ответов и взаимодействия с бэкенд-API.

Доработка фичей:

- Добавлена страница с правильными ответами.

- Улучшена логика кнопки "Пропустить".

- Переход с URL-параметров на sessionStorage для управления состоянием.

- Рефакторинг в SPA: Превращение набора HTML-страниц в полноценное одностраничное приложение с использованием классов, модулей и Webpack.

- Интеграция авторизации: Добавление системы аутентификации и переход на локальный бэкенд для полного контроля над полным циклом разработки.
